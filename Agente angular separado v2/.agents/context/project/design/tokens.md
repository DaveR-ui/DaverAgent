# 🎨 SafeGuard Tokens

## Colors

| Category | Token | Value | Purpose |
| :--- | :--- | :--- | :--- |
| **Primary** | `--color-primary` | `#dc2626` | Safety, Urgency, Brand Identity |
| | `--color-primary-dark` | `#991b1b` | Hover states, active states |
| **Secondary** | `--color-secondary` | `#0f172a` | Headers, Text, Professionalism |
| **Accent** | `--color-accent` | `#f59e0b` | Warnings, attention-grabbing elements |
| **Success** | `--color-success` | `#10b981` | Validation, safe status |
| **Neutral** | `--color-neutral-50-900` | Slate Palette | Backgrounds, borders, subtle text |

## Typography

- **Sans (Body)**: `Inter` - Optimized for readability in technical data.
- **Display (Headings)**: `Outfit` - Modern, authoritative, high impact.

| Level | Size | Weight | Line Height |
| :--- | :--- | :--- | :--- |
| Display LG | `3.5rem` | `700` | `1.1` |
| Headline MD | `2rem` | `600` | `1.2` |
| Body Base | `1rem` | `400` | `1.5` |
| Label SM | `0.875rem` | `500` | `1.4` |

## Spacing

Scale used for margins, padding, and gaps:
- `xs`: `0.25rem`
- `sm`: `0.5rem`
- `md`: `1rem`
- `lg`: `1.5rem`
- `xl`: `2rem`
- `2xl`: `3rem`

## Borders & Radii

Sharp, precise rounding for a "solid" feel:
- `radius-sm`: `0.25rem`
- `radius-md`: `0.5rem`
- `radius-lg`: `1rem`
