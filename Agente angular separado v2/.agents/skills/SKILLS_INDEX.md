## 🔄 Source & Generation Map

### Generation Logic
Skills in this project are generated and maintained through these sources:

1.  **Meta-Evolution**: Generated by the agent using `p3-ia-skill-creator` when a new reusable pattern is identified.
2.  **External Injection**: Adapted from official documentation (Angular/Tailwind) and distilled into `.md` instructions.
3.  **Task Memory Extraction**: Distilled from `task-memory.md` when a specific problem-solving pattern proves efficient.
4.  **AutoSkill Ecosystem**: Managed via `skills-lock.json` and the `autoskill` extension.

### Lifecycle of a Skill
`Idea` ➔ `Ad-hoc implementation` ➔ `Pattern Identification` ➔ `Distillation (p3-ia-docs-gen)` ➔ `Skill Creation (p3-ia-skill-creator)` ➔ `Registration (SKILLS_INDEX.md)`.

---

## 🚦 Integration Workflow
- **Mandatory Entry**: `p3-ia-analyzer` is the only valid entry point for any task.
- **Dependency Flow**: `analyzer` ➔ `explorer` ➔ `supplier` ➔ `proposer` ➔ `verifier` ➔ `learner`.
- **Scope Rule**: No skill may create files outside its defined scope (managed by `p2-proj-navigator`).
