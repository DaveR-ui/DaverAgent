## How to Use

Each topic folder contains an `index.md` file that lists the files available in that folder.
To find information about a specific topic, navigate to the corresponding folder and read its index.

## Adding New Topics

To add a new topic:
1. Create a new folder under `angular/`
2. Add an `index.md` file listing the documentation files
3. Add the topic to this root INDEX.md table
